# Delamare Farm E-commerce Platform

Online marketplace for Delamare Farm Kenya - selling livestock, crops, and farm supplies nationwide.

## Features

- 🐄 **Livestock**: Dairy cows (Friesian, Ayrshire, Girolando), goats (Saanen), sheep (Dorper, Hampshire Down)
- 🌽 **Crops**: Fresh tomatoes, capsicum, maize, potatoes
- 🐓 **Poultry**: Chickens, guinea fowls, quails, geese, turkeys
- 🛒 **Shopping Cart**: Add items and order via WhatsApp
- 📱 **Responsive Design**: Works on mobile, tablet, and desktop
- 🚚 **Countrywide Delivery**: 24-hour delivery across Kenya

## Tech Stack

- React 18 with TypeScript
- Vite for build tooling
- Tailwind CSS for styling
- React Router v6 for navigation
- React Context for cart management
- Lucide React for icons

## Installation
